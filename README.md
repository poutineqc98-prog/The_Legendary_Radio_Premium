# THE LEGENDARY RADIO — FINAL PREMIUM EDITION (v4.1)

Application musicale Android haut de gamme connectée à **Plex**, fidèle à la maquette visuelle officielle :
- **Icône officielle & identité :** Patte de chat DJ rose/cyan avec vinyle, bras de lecture et ondes radio (`ic_launcher_paw.xml`).
- **Lecteur CD & Boombox :** Boîtier CD transparent avec disque irisé rotatif portant la pochette réelle de l'album, façade boombox avec haut-parleurs et analyseur de spectre FFT réel (`android.media.audiofx.Visualizer`).
- **Bibliothèque CD Collectionneur :** Étagères en bois rétroéclairées avec tranches verticales, mode **Cover Flow 3D** avec reflets et mode Grille.
- **Navigation stricte :** 4 onglets permanents (`Artistes` regroupés par *Album Artist*, `Albums`, `Lecteur`, `Playlists`).
- **Monsieur Chat :** Animateur radio virtuel (Français canadien, Anglais canadien, Bilingue) avec météo locale en direct et interventions naturelles entre les morceaux.
- **Lecture en arrière-plan Android :** Service `MediaSession` complet (écran verrouillé, notifications, écouteurs Bluetooth).
- **Diffusion audio :** Bluesound NODE (« Home Cinéma » via BluOS port 11000), Google Cast, Bluetooth et Sonos.
- **Nothing Phone Glyph :** Pont natif prêt pour le Nothing Glyph Developer Kit.

---

## Comment obtenir le fichier `.apk` installable (sans rien installer sur votre PC)

1. Créez un nouveau dépôt sur **GitHub** (par exemple `the-legendary-radio`).
2. Extrayez cette archive ZIP et téléversez tous les fichiers dans le dépôt GitHub.
3. Allez dans l'onglet **Actions** de votre dépôt GitHub et lancez le workflow **Build Android APK (The Legendary Radio)**.
4. Une fois terminé (~2 minutes), téléchargez l'artefact **`The-Legendary-Radio-Premium-v4.1-APK`** contenant `app-release.apk` et installez-le sur votre Nothing Phone.
